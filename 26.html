第26章：联赛风格组合题精讲

把整个工具箱放到实战：集族双计数、圆排列极值、染色不变量。还原从读题到写出解答的完整思考链。

大家好，我是你们的讲师。经过前面25章的系统学习，我们从计数原理一路走到组合几何，从抽屉原理聊到概率方法。今天，是时候把所有这些武器放到实战中检验了。

在竞赛圈流传着一句话：“真题做三遍，胜过模拟题三十套。”真题是命题人精心打磨的产物，其思维密度和陷阱设计是模拟题难以企及的。更关键的是，做真题能让你真正理解命题人的思路——他们想考什么、喜欢用什么方式包装、在哪里设置思维障碍。

关于本章题目的说明：本章不引用任何具体年份联赛原题的原文（未经核实的“真题回忆”极易出错，也会误导读者）。下面讨论的三道题是按联赛二试的典型风格与难度编写的教学改编题，目的是示范“从读题到写出解答”的思考路径与方法选择。请把它们当作方法训练题，而不要当作历年真题索引。

26.1 组合题的“方法地图”

面对一道组合题，先判断它属于哪一类，往往就能圈定主力方法。下面是一张定性的方法地图（基于教学经验的归纳，非统计数据）：

题目信号首选方法典型场景
涉及“操作 / 状态变化”不变量、势函数染色翻转、开关灯
涉及“必然存在”抽屉原理、极端原理存在性、图论
涉及“求最大 / 最小”下界估计 + 构造组合极值
涉及“同一量算两次”双计数集族、关联结构
涉及“n → n+1”归纳法构造、递推

接下来三节分别用一道教学改编题演示其中三类方法：双计数、交换论证、染色不变量。

26.2 题型一：集族与双计数

题目呈现

先看一道集族极值题（教学改编题）：

题目：设正整数 n ≥ 3，A₁, A₂, ..., Am 是 {1, 2, ..., n} 的不同的子集，满足：

  • （i）对任意 i ≠ j，|Ai ∩ Aj| = 1；
  • （ii）对任意 i，|Ai| ≥ 2。

求 m 的最大可能值。

读完题，你的第一反应是什么？很多同学会想："这不就是两两交集大小为1吗？那所有子集的公共交集呢？"——这是一个自然的联想，但这种联想会让你立刻掉进制式思维的陷阱。

思考路径还原

我们一步一步还原考场上应该怎么想：

第一步：提取信号。题目给了三个关键信息：①两两交集大小为1；②每个子集至少2个元素；③求m的最大值。关键词是"最大可能值"，这意味着我们需要构造一个下界 + 证明一个上界。

第二步：先想构造。最简单的构造：取公共元素 x，令 Ai = {x, yi}（yi 取遍其余 n−1 个元素），得到 n−1 个满足条件的子集。但还能更多！把这 n−1 个集合与一个“大集合” An = {y₁, …, yn−1}（即除 x 外的全部元素）放在一起，就得到“近铅笔”构造。验证：{x,yi} ∩ {x,yj} = {x}；{x,yi} ∩ An = {yi}，交集都是单元素，且 |An| = n−1 ≥ 2。于是共有 n 个子集。

第三步：猜测答案。构造给出 m ≥ n。能否超过 n？直觉上不行——每个子集都必须与其它所有子集“恰好共享一个元素”，这种共享关系把集族约束得很紧。下面我们来证明 m ≤ n。

第四步：选择证明方法。这里有一个重要的决策节点：用什么方法证明上界？

方法A（双计数）：计算有序对 (x, i) 的数量，其中 x ∈ Ai。设 d(x) 表示元素x出现的次数，则 ∑d(x) = ∑|Ai|。再算另一个方向上的有序对 (i, j, x) 其中 x ∈ Ai∩Aj。这看起来可行但需要巧妙构造。

方法B（线性代数）：构造关联矩阵 M，其中 Mxi = 1 当 x ∈ Ai。则 MTM 的非对角元全为 1（= |Ai∩Aj|），对角元为 |Ai|，分析这个矩阵的秩可以得到限制。但联赛中线性代数不是默认工具——不一定每个阅卷老师都接受。

方法C（组合推理）：两两交集为1意味着集族的结构非常特殊。可以用反证法：假设m ≥ n，然后导出矛盾。

双计数方法的框架：
设 d(x) = 包含元素 x 的子集个数。
则 ∑_{x=1}^{n} d(x) = ∑_{i=1}^{m} |A_i|    （1）

另一方面，考虑任意两个不同的子集 A_i, A_j：
|A_i ∩ A_j| = 1，所以 ∑_{i<j} |A_i ∩ A_j| = C(m,2)

将这个量用 d(x) 表示：
∑_{i<j} |A_i ∩ A_j| = ∑_{x=1}^{n} C(d(x), 2)    （2）

由（1）（2）及条件 |A_i| ≥ 2 可得：
∑_{x=1}^{n} C(d(x), 2) = C(m, 2)

关键引理（Fisher 不等式）：若 |A_i ∩ A_j| = λ 且 |A_i| > λ 对所有 i 成立，
则 m ≤ n。本题 λ = 1、|A_i| ≥ 2，故 m ≤ n。
|Ai∩Aj|=λ,|Ai|>λ⟹m≤n

第五步：完成证明。由 Fisher 不等式（取 λ = 1）立即得到 m ≤ n；结合第二步的构造，最大值恰为 n。双计数与 Cauchy 放缩可以给出这条不等式的组合证明，线性代数则给出下面的简洁证明。

方法选择：这道题用双计数（把“两两交集”的和转化为 ∑ C(d(x),2)）是联赛里最常见的稳妥写法，阅卷不会有争议；线性代数证明更短，但需要阅卷标准接受矩阵工具。两条路都指向同一个上界 m ≤ n。

另一种解法比较

用线性代数更简洁。构造 n×m 的关联矩阵 M，其列为各子集的特征向量 vi。则 G = MTM 是 m×m 矩阵，Gii = |Ai|，Gij = 1 (i≠j)。把它写成 G = D + J，其中 D = diag(|Ai|−1)、J 为全 1 矩阵。由 |Ai|−1 ≥ 1 知 D 正定，且 G 正定（det G = ∏(|Ai|−1)·(1 + Σ 1/(|Ai|−1)) > 0），故 G 可逆，于是 m = rank(G) ≤ rank(M) ≤ n。

两种方法相比：双计数更"组合"，线性代数更"暴力"。在考场上，如果你对线性代数更自信，方法B能更快写出答案；但如果你不确定阅卷标准是否接受矩阵方法，双计数是更保险的选择。

26.3 题型二：圆排列上的交换论证（教学改编题）

题目呈现

再看一道典型的组合极值题：

题目：设n是正整数。将1, 2, ..., 2n这2n个数排成一个圆（即考虑旋转相同的排列视为同一种），称排列中相邻两个数的乘积之和为该排列的"邻乘积和"。求所有排列中邻乘积和的最小可能值，并给出取到最小值的排列。

题目的设定不复杂，但难度在于：极值的下界估计和构造需要同时进行，缺一不可。

思考路径还原

第一步：读懂问题。把1到2n排成一个圆圈，对每个相邻对（包括首尾）求乘积再求和。我们要让这个和尽可能小。

第二步：直觉方向。为了让乘积尽可能小，我们自然想把"大数和小数"配对——比如让最大的数2n和最小的数1相邻，这样2n×1 = 2n就很小；而如果把2n和2n-1放在一起，2n×(2n-1)会非常大。所以核心直觉是：大小交替排列。

第三步：用不等式进行初步估计。这是一个非常经典的技巧——通过排序不等式给出邻乘积和的下界。把2n个数按某种顺序排列在圆上，总共有2n个相邻对。设这些数为a₁到a₂n，则邻乘积和 S = a₁a₂ + a₂a₃ + ... + a₂n-1a₂n + a₂na₁。

S=∑i=12naiai+1,a2n+1:=a1

第四步：从特殊到一般。先试试n比较小的情况：当n=1时只有两个数1和2，S=1×2+2×1=4。当n=2时，1,2,3,4排成圆，试试大小交替：1,3,2,4得到S=1×3+3×2+2×4+4×1=3+6+8+4=21；而如果按1,2,3,4得到S=1×2+2×3+3×4+4×1=2+6+12+4=24。大小交替确实更优！

第五步：求和公式的推导。其实S有一个重要的恒等式：

考虑 (a₁ + a₂ + ... + a_{2n})² 的展开：
(∑a_i)² = ∑a_i² + 2∑_{i<j} a_i a_j

而 S = ∑_{i=1}^{2n} a_i a_{i+1}（其中 a_{2n+1}=a₁）

注意到 S 只是所有两两乘积之和的一部分，
我们无法直接求 S 的最小值，但可以通过重新排列不等式来估计。

第六步：交换论证与下界。这道题的真正难点在于同时给出构造（证明某值可达）与下界（证明不可能更小）。核心工具是交换论证：如果圆上存在某种“逆序”结构——例如存在两对相邻元素 a<b、c<d 被摆放成 a,b,…,c,d，把 b 与 c 互换后会严格减小 S——那么反复交换直到不能再减小，得到的局部极小排列必定呈“大数两侧都接小数”的交错形态。这种形态就给出了下界的形状；要写成严格的闭式，需按 n 的奇偶分情况讨论，本文只示范小情形。

极值题的两个半场：答案必须两头齐——既给构造（证明某值可达），又给下界（证明不可能更小）。只写构造只能说明该值可达，并不能说明它最小；只写下界则不知道它是否能达到。此外，放缩时务必注意不等号方向：想证“最小”就要证一个下界，方向搞反会証反结论。

选择 n，穷举所有圆排列，找出最小的邻乘积和。

26.4 题型三：染色与不变量（教学改编题）

题目呈现

第三道是一道染色不变量题：

题目：将 n×n 棋盘（n ≥ 3）的每个格子染成红色或蓝色。定义一次操作为：选择一个2×2正方形，将其四个格子的颜色全部翻转（红变蓝、蓝变红）。问：能否通过若干次操作，使棋盘上所有格子变为同一种颜色？如果能，给出操作方案；如果不能，说明理由。

乍一看很简单——每次翻转2×2的四个格子，看起来能"翻转一切"。但稍微试验一下就会发现：有些初始染色状态是永远无法变成全同色的。为什么？

思考路径还原

第一步：找不变量。这类问题的标准套路就是寻找操作过程中的不变量——某种在操作前后保持不变的性质，如果初始状态和目标状态在这个性质上不同，就说明不可达。

第二步：试验小规模。在2×2棋盘上（虽然题目要求n≥3），一次操作恰好翻转所有格子。如果初始状态有奇数个蓝格，操作一次后仍然有奇数个蓝格（因为翻转4个格子改变偶数个蓝格）。奇偶性不变！

第三步：推广到n×n。考虑将棋盘按如下方式标号：

用 (i, j) 表示第 i 行第 j 列。
考虑所有形如 (i, j) 满足 i+j 为偶数的格子。
一次操作翻转一个2×2正方形，其中恰好有2个这样的格子（因为2×2正方形中两白两黑）。
所以这些格子的蓝色个数 mod 2 在操作下保持不变。

第四步：得出结论。对于n≥3，如果初始状态在所有i+j为偶数的格子中，蓝色格子的数量是奇数，那么永远无法将整个棋盘变成全红（因为全红时这个数量为0，是偶数）。类似地，也无法变成全蓝（因为全蓝时这个数量等于偶数位置的总数，如果总数是奇数——这取决于n的奇偶性）。

第五步：方案构造。如果初始状态满足可达条件（所有不变量匹配），则可以通过一系列操作实现全同色。构造方法很简单：逐行扫描，每个格子如果颜色不对，就以它为左上角进行一次操作（对于右下角边缘需要特殊处理）。

实战经验：染色操作类问题是联赛中的"常青树"。从2000年代初至今，几乎每3-4年就会考一次。这类问题有一个通用的思维框架：①找到操作下的不变量（奇偶性、模k的和、某种加权和）；②用不变量判断不可行的情形；③对可行的情形给出构造方案。记住这个框架，遇到操作类问题就能快速建立思路。

26.5 三道题的方法回检

把上面三道教学改编题放在一起，可以提炼出一个共通的解题节奏（教学归纳，非统计结论）：

题核心工具关键一步
集族题双计数 / Fisher 不等式把两两交集之和写成 ∑ C(d(x),2)，得到 m ≤ n
圆排列题交换论证局部换序严格减小 S，直到成大小交错
染色题奇偶不变量2×2 翻转改变各类同色格各偶数个，奇偶性不变

共同点：三道题都不是靠“算出答案”，而是靠先锁定一个在操作或结构下不变、或单调的量，再用它卡住极值或排除不可达。这正是前面各章反复强调的方法论：找不变量、找单调量、找可算两次的相对量。

26.6 临场快速试错策略

在考场上，时间是最宝贵的资源。面对一道陌生的组合题，你不可能把所有方法都试一遍。这里分享一套我多年的"方法论轮换检查表"，帮助你在最短时间内找到正确的方向。

第一步（1-2分钟）：识别题型。

  • 是"求值/计数"还是"证明/判断"？——前者用计数公式/递推/母函数；后者用反证/构造/归纳。
  • 是"极值/最值"还是"存在性"？——前者需要构造+估计；后者用抽屉/极端/概率。
  • 涉及"操作/变化"吗？——马上想不变量/势函数。
  • 涉及"染色/图"吗？——马上想图论工具/Ramsey。

第二步（3-5分钟）：尝试主力方法。

  • 不变量（如果涉及操作或变化）
  • 抽屉原理（如果涉及存在性或划分）
  • 极端原理+反证法（如果涉及最大/最小对象）
  • 双计数（如果涉及计数两种不同方式）

第三步（5-8分钟）：如果主力方法不奏效。

  • 退回到特殊情形：试n=1,2,3或小规模枚举——你会发现规律。
  • 换视角：把问题翻译成集合/图/多项式等不同语言。
  • 用归纳法：从n到n+1能否推过去？

第四步（8-10分钟）：如果还是不行。

🚨 重要提醒：如果你试了10分钟还没有找到任何方向，果断跳过这道题，先做其他题目！二试的4道题分值相同，在一道题上死磕20分钟不如先拿下另外两道的分数。等所有题目都过了一遍再回来，有时候"放下再拿起"反而能发现新思路。

26.7 本章小结

今天我们做了三件重要的事：第一，通过三道教学改编题，我们还原了从读题到写出解答的完整思考链路；第二，我们提炼了几类高频方法（不变量、双计数、交换论证）的适用信号；第三，我们总结了临场试错的策略框架，帮助你在不同方法之间快速切换。

下一章，我们将走出联赛，放眼 IMO——看看世界顶级竞赛中的组合名题是什么样子。你会发现，许多联赛题的“祖先”就来自 IMO，理解了这些经典题，联赛的难题也就不再神秘了。

记住我今天的这句话：做题，不是为了背答案，而是为了训练“看到题目就知道用什么方法”的直觉。这种直觉，只有在反复的思考-验证-修正中才能真正建立。
