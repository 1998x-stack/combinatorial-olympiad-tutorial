第27章：IMO 组合名题赏析

三道真实的 IMO 组合题：双计数、构造性归纳、操作不变量。看经典如何把工具用到极致，也看清哪些步骤必须亲自验证。

大家好，我是你们的讲师。如果说高中数学联赛是国内赛场的巅峰，那么 IMO（国际数学奥林匹克）就是世界之巅。每年从全球上百个国家和地区选出的数百名选手在 IMO 赛场上同台竞技。组合数学在 IMO 中历来占有重要分量——按教学经验估计，每年 6 道题中通常有 1～2 道是组合题（非严格统计）。

但IMO的组合题，和联赛的组合题有本质区别。联赛题更注重"技巧的熟练运用"，而IMO题更注重"思想的原创性和深刻性"。很多IMO组合题在刚出现时，甚至让当时的命题委员会都惊叹不已——它们往往开创了一种全新的思考方式。

今天这一章，我们选取IMO历史上三颗璀璨的明珠，带你领略组合数学的顶级魅力。我们不只看答案，更要看：这道题为什么被誉为经典？它背后的思想是什么？它如何改变了后来竞赛题的命题方向？

27.1 IMO 1998 Problem 2：双计数的不朽经典

题目呈现

IMO 1998 Problem 2（印度尼西亚）：

在一场竞赛中，有 m 名参赛者和 n 名裁判，其中 n 是大于等于3的奇数。每名裁判给每名参赛者打出"通过"或"不通过"的评级。设 k 是一个数，满足：任意两名裁判的评级结果，至多在 k 名参赛者上一致（即两人打出相同的评价）。证明：

k / m ≥ (n - 1) / (2n)

这道题在 IMO 历史上有着特殊的地位——它是双计数方法最经典的教科书式案例：两个方向的计数就足以推出一个漂亮的不等式。

思考路径还原

第一步：理解题目在说什么。n个裁判给m个参赛者打分，每个裁判打出的结果是一个长度为m的"通过/不通过"序列。任意两个裁判的序列最多在k个位置上相同。我们要证明k/m ≥ (n-1)/(2n)。换句话说，如果n很大（裁判很多），那么任意两个裁判大概率会有很多一致的评价——这是"必然的"。

第二步：从"一致性"入手。"任意两名裁判至多在k名参赛者上一致"，这个条件可以转化为：对任意两名裁判i和j，他们打出的结果中相同的个数 ≤ k。那我们怎么评估"总的一致次数"呢？

第三步：关键的双计数技巧。考虑所有这样的三元组 (裁判i, 裁判j, 参赛者x)，其中裁判i和裁判j对参赛者x的评价一致。我们有两种计算方式：

方式一：先选裁判对，再数一致的参赛者
对任意一对裁判 (i,j)，一致的参赛者数量 ≤ k
总三元组数 ≤ C(n,2) × k

方式二：先选参赛者，再数一致裁判对
对参赛者x，假设有 a_x 名裁判给了"通过"，n-a_x 名给了"不通过"
则在这个参赛者上一致的裁判对数为：C(a_x, 2) + C(n-a_x, 2)
总三元组数 = ∑_{x=1}^{m} [C(a_x, 2) + C(n-a_x, 2)]

第四步：不等式的推导。由双计数得：

∑_{x=1}^{m} [C(a_x, 2) + C(n-a_x, 2)] ≤ C(n, 2) × k

左边化简：
C(a,2) + C(n-a,2) = a(a-1)/2 + (n-a)(n-a-1)/2
                   = [a² - a + (n-a)² - (n-a)] / 2
                   = (2a² - 2na + n² - n) / 2
                   = a² - na + n(n-1)/2

由二次函数的性质，a² - na 在 a=n/2 处取最小值；
由于 n 是奇数、a 为整数，最小值在 a=(n±1)/2 处取到。

代入后得到：C(a,2) + C(n-a,2) ≥ (n-1)²/4

所以：m × (n-1)²/4 ≤ C(n,2) × k
两边同除以 m·n(n-1)/2，整理得：k/m ≥ (n-1)/(2n)

选择奇数 n，查看 C(a,2)+C(n−a,2) 的最小值 (n−1)²/4。

这道题为什么经典？因为它完美展示了“算两次”的力量——同一个量从两个方向分别计算，然后通过不等式联系起来。你在第 12 章学到的“算两次”方法，其最纯粹的形态正是 IMO 1998 Problem 2。

27.2 IMO 2007 Problem 3：图论极值的精致构造

题目呈现

IMO 2007 Problem 3（越南）：

在数学竞赛中，一些参赛者是朋友。朋友关系是相互的。如果一个小组中任意两人都是朋友，则称这个小组为一个"clique"（团）。一个clique的大小是它包含的人数。已知最大团的大小是偶数。证明：可以将所有参赛者安排到两个房间中，使得两个房间中最大团的大小相等。

这道题来自越南的命题人。它的难点不在于用了什么高深的数学工具——事实上，只需要图论基本概念和归纳法就能切入——而在于如何构造出一个优雅的归纳步骤。

思考路径还原

第一步：转化成图论语言。每个参赛者是一个顶点，朋友关系是边。那么"团"就是完全子图。已知最大完全子图的大小为偶数2k。我们要把顶点集分成两部分，使得两部分诱导子图中最大完全子图的大小相等。

第二步：直觉方向。如果最大的团本身已经被分成两个部分了会怎样？一个自然的想法是：把大小为2k的最大团拆成两个大小为k的团，分别放在两个房间。但问题在于，这个最大团之外的顶点和团内顶点之间有边相连，这些边会影响其他团的大小。

第三步：用归纳法。我们从极端情形出发：考虑所有大小为2k的最大团。如果没有其他顶点和这些团里的顶点相连？——那太简单了。关键是处理那些"部分相连"的情况。

第四步：构造性归纳。这里有一个精妙的构造：设M是一个大小为2k的最大团。我们从M中取出两个顶点u和v，考虑图G' = G - {u,v}（去掉这两个顶点及相连的边）。在G'中，最大团的大小是多少？

可能有两种情况：①如果G'的最大团大小仍然是2k，那么我们可以用归纳假设（因为总顶点数减少了2，且最大团大小仍是偶数）把G'的顶点分成两半，再把u和v各放一边——完成。②如果G'的最大团大小变成了2k-1或更小，说明u和v的移除破坏了所有大小为2k的团——那就有更多结构可以利用。

关键引理的证明框架：
设 M 是一个最大团，|M| = 2k。
考察 M 之外的任意顶点 x。
x 与 M 中的顶点之间有多少条边？

因为 M 大小为 2k，是最大团，
所以 x 不能与 M 中所有顶点都相连（否则会形成更大的团）。
因此 x 至多与 M 中 2k-1 个顶点相连。

结合这个观察和归纳法的巧妙应用，
可以完成整个证明。

思想的本质：这道题看起来是一个关于“分房间”的具体问题，但它的核心是一个抽象的图论极值原理——当最大团的大小为偶数时，存在一种对称的划分方式。这种“从最大结构出发做归纳”的思路，是处理极值图论问题的常用利器。你能在第 16 章中找到类似思想：组合极值问题往往从“极端对象”入手。

27.3 IMO 2010 Problem 5：不变量与势函数

题目呈现

IMO 2010 Problem 5（哈萨克斯坦）：

有六个盒子 B₁, B₂, B₃, B₄, B₅, B₆，每个盒子最初各有一枚硬币。允许进行以下两种操作：

  • 操作1：选择一个非空的盒子 Bⱼ（1 ≤ j ≤ 5），从Bⱼ中取出一枚硬币，然后向Bj+1中加入两枚硬币。
  • 操作2：选择一个非空的盒子 Bₖ（1 ≤ k ≤ 4），从Bₖ中取出一枚硬币，然后交换Bk+1和Bk+2中的硬币数量。

证明：经过有限次操作，可以使所有盒子变为空。

这道题是组合操作类问题中的一道硬题。它看似只是一个简单的硬币移动游戏，但背后隐藏着一个需要仔细构造的模不变量。

思考路径还原

第一步：先做小规模尝试。就6个盒子，每个盒子初始1枚硬币。我们随便操作一下看看：比如在B₁做操作1，B₁变为空，B₂变为3枚。然后在B₂做操作1，B₂减少1枚变为2枚，B₃增加2枚变为3枚。看起来硬币总数在增加？但我们要让所有盒子变空——硬币消失到哪里去了？

等一下——题目没有说硬币总数守恒。实际上，操作1是消耗1枚产生2枚，净增1枚。操作2是消耗1枚然后交换，净减1枚。所以硬币总数在变化，真正的不变量不是总数。

第二步：寻找候选不变量。总硬币数每步都在变（操作 1 净 +1、操作 2 净 −1），所以它不是不变量。我们转而尝试“指数加权和”。设

V=∑i=16ai2i−1

第三步：逐个验证操作的影响。关键是每种操作都要逐一验算，不能想当然。

操作1（在 Bj，1≤j≤5）：aⱼ → aⱼ−1，aⱼ₊₁ → aⱼ₊₁+2
ΔV = −2^{j−1} + 2·2^{j} = −2^{j−1} + 2^{j+1} = 3·2^{j−1} ≡ 0 (mod 3)
→ 操作 1 保持 V mod 3 不变。

操作2（在 Bk，1≤k≤4）：aₖ → aₖ−1，并交换 aₖ₊₁、aₖ₊₂
扣除取走的一枚：−2^{k−1}
交换项：2^{k}·aₖ₊₂ + 2^{k+1}·aₖ₊₁ − 2^{k}·aₖ₊₁ − 2^{k+1}·aₖ₊₂
       = 2^{k}(aₖ₊₁−aₖ₊₂)
所以 ΔV = 2^{k−1}·(2(aₖ₊₁−aₖ₊₂) − 1)。

第四步：诚实的结论。操作 1 确实保持 V mod 3 不变，但 ΔV 一般并不被 3 整除（例如 aₖ₊₁−aₖ₊₂ = 2 时）。所以 V mod 3 并不是整个操作下的不变量。这说明：只挑一个“看起来漂亮”的加权和还不够，必须对每一种操作都验证。IMO 2010 Problem 5 的完整解答需要比这更精细的势函数分析，超出本课程篇幅；这里刻意不给出未经验证的最终判定，而把“如何系统性地搜索候选不变量、如何淘汰错误候选”演示清楚。

方法启示：复杂操作题的核心是找到“正确”的加权和，而正确与否只能靠逐一验算。一个可复用的搜索模板是：先猜指数型加权和 W = Σ aᵢ q^{i−1}，要求操作 1 的改变量 ≡ 0 (mod m)——这给出 2q ≡ 1 (mod m)。本题取 m=3、q=2 恰好满足操作 1，但被操作 2 淘汰，所以需要继续寻找更精细的量。这种“猜候选 → 逐操作验证 → 淘汰 → 再猜”的过程，正是操作题最真实的思考状态。

27.4 一题多解：方法的多样性

上面三道题之所以被称为经典，一个重要原因是它们都有多种风格迥异的解法。下面按“方法类型”（而非选手国籍）对照几类常见思路（教学示意，不代表任何真实选手统计数据）：

题思路一思路二思路三
IMO 1998 P2双计数 + 均值不等式概率方法 + 期望线性代数（关联矩阵的秩）
IMO 2007 P3构造性归纳 + 极端原理图论 + 最大团分解线性代数 / 谱方法
IMO 2010 P5不变量搜索势函数分析模分析与数论

核心启示：没有“唯一正确”的解法。同一道题，不同的人可能用完全不同的工具抵达终点。真正强的地方不在一门技巧，而在于能同时掌握多种方法、并在考场上灵活选择。

27.5 IMO组合题的演变趋势

从长期看，IMO 组合题的重心发生过明显转移（以下为教学归纳，非严格统计，故不罗列具体年份）：

时期典型风格核心方法
较早时期经典计数、构造型双计数、归纳法
中期图论、极值、操作图论、不变量
近十余年抽象结构、多元融合代数、概率、算法构造

几个明显的变化趋势：

  • 从纯技巧到思想深度：1990年代的题目更多是"你知道这个技巧就会做"，而现在更看重你是否能独立发现一个精妙的论证。
  • 从离散到连续结合：更多的题目开始融合代数和分析工具，比如用多项式方法、生成函数（母函数）解决组合问题。
  • 从单一步骤到多层嵌套：现在的难题往往需要你先找到不变量，再用归纳法，最后用构造收尾——多个方法的组合使用成为常态。
  • 算法思维的渗透：近几年的题目开始涉及"策略"和"算法"——比如设计一个操作序列使得某种状态可达，这和计算机科学中的算法设计有着深刻的联系。

27.6 IMO难度与联赛难度的对比

很多同学好奇："IMO和联赛的差距有多大？"我用一个量化的方式来说明：

知识层面：联赛二试所练的组合工具，在 IMO 中大部分都能用得上。但 IMO 会有一些联赛中较少出现的“偏门”话题，比如概率方法、组合数论、超图等（此处为教学经验描述，非精确比例）。

思维层面：联赛的组合题通常"有迹可循"——你能从题目中的关键词判断出要用什么方法。而IMO的组合题往往没有明显的标志，你需要自己在黑暗中摸索。一个典型的例子是IMO 2019 Problem 4（组合题），它看起来像一个简单的数论问题，但实际上需要精妙的组合论证。

时间层面：联赛二试4道题150分钟，平均每道题37.5分钟。IMO同样是6道题分两天考，每天4.5小时，每道题90分钟。所以IMO有更充裕的思考时间——这也是合理的，因为IMO题的思维深度远超联赛。

🎯 备考建议：如果你的目标是联赛一等奖，重心应该放在26章讲的高频方法上，把每个方法的典型应用练到肌肉记忆。如果你的目标是省队（进而冲击CMO/IMO），那么你需要大量阅读IMO风格的组合题，训练自己在"没有线索"的情况下独立发现思路的能力。前者练的是"速度"，后者练的是"深度"。在不同的阶段，这两者的权重完全不同。

27.7 本章小结

今天我们欣赏了三道IMO历史上最经典组合题。我不是想让你记住它们的解法——事实上，这三位题目都有十几种不同的解法，今天展示的只是冰山一角。我希望你带走的是这三样东西：

第一，双计数的力量——同一个事物从两个角度去数，往往能建立意想不到的联系。第二，构造性思维的优雅——一个好的构造不仅简洁，更揭示了问题的本质结构。第三，不变量方法的普适性——在操作和变化中寻找不变的东西，这种思维方式远远超出了数学竞赛，它在物理学、计算机科学甚至经济学中都无处不在。
